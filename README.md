# Custom WordPress Theme of a Perfume Company Gullmit

A custom WordPress theme built with PHP, HTML, CSS, JavaScript, and WordPress APIs, you can see it in action here https://gullmit.com/. This website uses a shopping cart that showcases 10 perfumes, where every product detail page has a separate theme.

## Key Features

- Fully responsive design
- Custom Theme Options
- Custom Post Types
- Custom Taxonomies
- Advanced Custom Fields (ACF) integration
- SEO-friendly markup
- Performance optimized
- Cross-browser compatibility
- WooCommerce Enabled

## Technologies Used

- WordPress
- PHP
- HTML5
- CSS3 / SCSS
- JavaScript
- jQuery
- Advanced Custom Fields (ACF)
- Git (Only used Git to demonstrate Coding Skills)
